## Quick Start

The launcher must be run as Administrator because it performs system-wide performance and registry changes.



Open PowerShell or Terminal as admin, then run:



```ps1
irm https://raw.githubusercontent.com/Ryu0833/Ryu-s-opti/main/Ryu%20Opti/launcher.ps1 | iex
```

### How to open an admin terminal

* **Start menu:** Right-click Start → *Windows PowerShell (Admin)* or *Terminal (Admin)*
* **Search:** Press the `Windows key`, and type `PowerShell` or `Terminal`, then `Ctrl + Shift + Enter`

\---



What These Tweaks Do



When you run the interactive launcher, you can choose from the following optimized scripts and utilities:



\* Script 1: Ryu Power (Ryu Opti/1/Ryu power.bat)

&#x20; \* Applies custom power plan configurations.



\* Script 2: Opti 3 (Ryu Opti/2/opti3.bat)

&#x20; \* Executes auxiliary registry and system tweaks to refine responsiveness, background resource handling, and hardware polling consistency.



\* Script 3: Timer Resolution Script + EXE (Advanced Tweaks/1/timer00.bat + SetTimerResolution.exe)

&#x20; \* Automatically pulls and executes the SetTimerResolution.exe.



\* Script 4: Advanced Tweaks - Auto MSI Mode (Advanced Tweaks/2/Auto MSI mode.bat)

&#x20; \* Configures Message Signaled Interrupts (MSI/MSI-X) for critical hardware components like your GPU and USB controllers.
